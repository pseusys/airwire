airwire obfuscation demo

A message never looks like ciphertext on the wire — it's disguised as something ordinary instead: plausible-looking sentences, or a patterned image. Both use the same trick underneath: an arithmetic coder run backwards, turning random-looking bits into a sequence of weighted choices, and back again. See core/README.md for the full explanation.

This page showcases only the disguise mechanism: message bytes in, disguised output out, and back. There is no encryption, no chunking, no handshake here — those live in the real Python protocol (core/). What you type below is fed to the encoder exactly as you typed it, not as ciphertext.
